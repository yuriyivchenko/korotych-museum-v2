# Музей вчителя — прототип цифрового музею

Прототип веб-проєкту «Музей вчителя» створений для демонстрації цифрової пам’яті навчального закладу. Це односторінковий інтерфейс з маршрутизатором, який відображає сторінки: головну, стіни, стійки, архів, відгуки, контакти та про нас.

## Опис

Зверстано як SPA-прототип з динамічним завантаженням JavaScript-модулів через `loader.js`.

- `index.html` — основна сторінка
- `css/style.css` — стилі
- `js/loader.js` — скрипт завантаження та ініціалізації
- `js/core/router.js` — простий маршрутизатор
- `js/pages/` — окремі сторінки програми
- `js/data/` — дані для архіву, відгуків, стендів, стін тощо
- `js/modals/modal.js` — логіка модальних вікон

## Структура проєкту

- `index.html` — точка входу веб-додатку
- `css/style.css` — стилі інтерфейсу
- `images/` — медіа-ресурси, зокрема логотип
- `js/core/router.js` — маршрутизація та обробка кнопок
- `js/pages/` — рендер сторінок у контейнер `#app`
- `js/data/` — дані для відображення контенту
- `js/modals/modal.js` — робота з модальними вікнами
- `js/loader.js` — завантажує залежності та запускає застосунок

## Як запустити

1. Відкрий `index.html` у браузері.
2. Перейдіть між сторінками через меню або кнопки з `data-route`.
3. Усе працює без серверної частини — достатньо локального відкриття в браузері.
